# FactoryFlow 요구사항 명세서 (Requirements - MVP 기준)

> 본 문서는 초기 개발 범위(MVP, Minimum Viable Product)를 정의합니다.
> 초기 구현 단계에서는 핵심 생산·재고 흐름에 집중하고, 로그인·고급 통계 등은 후속 단계로 분리합니다.

---

## 1. 골판지 상자 제조업 도메인 핵심 개념
- **원재료(Raw Material / Sheet)**: 상자를 만들기 위해 입고되는 골판지 원단(예: A골, B골, AB골 원단) 및 부자재
- **완제품(Finished Product / Box)**: 재단·인쇄·타발·접합 공정을 거쳐 완성된 골판지 상자(예: 택배박스 3호, 사과박스 10kg 등)
- **작업지시(Work Order)**: 특정 완제품 상자를 몇 개 생산할지 현장에 내리는 지시
- **생산실적(Production Result)**: 작업지시에 따라 실제로 생산한 양품 수량과 불량 수량 기록
- **재고 수불(Inventory Transaction)**: 입고(+), 생산 투입/출고(-)에 따른 재고 변동 이력

---

## 2. 기능 요구사항 (Functional Requirements)

### F1. 기준정보 관리 (Master Data)
- **F1-1. 품목 관리**: 원재료(원단/부자재)와 완제품(박스)을 구분하여 등록, 조회, 수정, 비활성화할 수 있다.
  - 필수 정보 예: 품목 코드(유니크), 품목명, 품목 구분(`RAW_MATERIAL` / `FINISHED_GOOD`), 규격(가로×세로×높이 또는 골 종류), 단위(매, 개, 롤), 안전재고 수량
- **F1-2. 거래처 관리**: 원단 매입처 및 박스 납품처를 등록·조회할 수 있다.

### F2. 생산 관리 (Production)
- **F2-1. 작업지시 등록 및 조회**: 생산할 완제품, 목표 수량, 예정일, 지시 상태(`WAITING`, `IN_PROGRESS`, `COMPLETED`, `CANCELED`)를 관리한다.
- **F2-2. 작업 상태 변경**: 대기 → 작업 중 → 완료 상태로 전환할 수 있다.
- **F2-3. 생산실적 등록**: 특정 작업지시에 대해 양품 수량과 불량 수량을 기록한다.
  - 누적 양품 수량이 목표 수량에 도달하면 작업 완료 처리가 가능해야 한다.

### F3. 재고 관리 (Inventory)
- **F3-1. 현재고 조회**: 품목별 현재 보유 수량과 안전재고 미달 여부를 한눈에 조회한다.
- **F3-2. 입고 / 출고 등록**: 원재료 입고 및 완제품 출고 수량을 등록한다.
- **F3-3. 생산-재고 연동(핵심)**:
  - 생산실적(양품)이 등록되면 해당 완제품 재고가 증가하고 재고 이력이 남아야 한다.
  - (확장) 품목 BOM(상자 1개당 필요 원단 수량)이 설정된 경우 원재료 재고가 자동 차감된다.
- **F3-4. 재고 변동 이력 조회**: 언제, 어떤 사유(입고, 출고, 생산완료, 수량조정)로 재고가 변동되었는지 추적할 수 있다.

### F4. 대시보드 (Dashboard)
- 금일 진행 중인 작업지시 건수, 금일 생산량/불량률, 안전재고 미만 품목 목록을 요약 조회한다.

---

## 3. 비기능 요구사항 (Non-Functional Requirements)
- **데이터 정합성**: 재고 수량은 절대 음수(`-`)가 되지 않도록 비즈니스 로직에서 검증하고 예외를 반환한다.
- **트랜잭션 보장**: 생산실적 저장과 재고 수량 변경은 하나의 트랜잭션으로 처리되어, 중간 실패 시 모두 롤백되어야 한다.
- **입력값 검증**: 수량은 0 또는 음수 입력 방지 등 서버 측 Validation을 필수로 적용한다.
- **보안**: DB 계정·비밀번호 등 민감 정보는 소스코드 및 Git 저장소에 저장하지 않는다.
- **API 일관성**: RESTful 경로(`/api/...`)와 일관된 JSON 응답/에러 형식을 사용한다.

---

## 4. 추후 확장 요구사항 (Post-MVP)
- 사용자 로그인 및 권한 분리 (관리자 / 현장 작업자)
- 설비별(인쇄기, 톰슨기, 접합기 등) 작업 배정 및 가동 상태
- 일별/월별 생산량 및 불량률 리포트 엑셀 다운로드
