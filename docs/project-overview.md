# FactoryFlow 프로젝트 개요 (Project Overview)

## 1. 프로젝트 배경 및 목적
소규모 골판지 상자 제조 현장에서는 여전히 작업지시서, 원단(원지) 사용량, 일일 생산량, 완제품 출고 및 현재고 파악을 **종이 전표나 수기 엑셀**에 의존하는 경우가 많습니다. 이로 인해 다음과 같은 문제가 발생합니다.

- 실시간 원재료·완제품 재고 파악 지연 및 오차 발생
- 작업지시 대비 실제 생산 진척률·불량률 추적 어려움
- 수기 입력 누락으로 인한 발주·납기 대응 지연

**FactoryFlow**는 이러한 문제를 해결하기 위해 만드는 **소규모 골판지 상자 제조업체용 Mini MES(Manufacturing Execution System)**입니다.

---

## 2. 핵심 목표
1. **실무 흐름 반영**: 품목(원재료/완제품) 등록 → 작업지시 발행 → 생산실적 등록 → 재고 자동 반영 및 이력 추적의 핵심 사이클 구현
2. **초보자 친화적 구조**: 과도한 엔터프라이즈 복잡성(MSA, 분산 캐시 등)을 배제하고, 표준적인 모놀리식 REST API + React SPA 구조로 견고하게 학습·구현
3. **데이터 신뢰성**: 재고 증감과 생산실적 기록이 트랜잭션 단위로 정확하게 일치하도록 설계

---

## 3. 시스템 아키텍처

```text
[사용자 브라우저]
       │  HTTP / JSON (개발 시 localhost:5173)
       ▼
[Frontend: React + Vite (frontend/)]
       │  REST API 호출 (fetch / axios -> localhost:8080/api/*)
       ▼
[Backend: Spring Boot 4.2 + Java 25 (루트)]
       │  Spring Data JPA (Hibernate)
       ▼
[Database: MySQL 8.0 (factoryflow DB)]
```

### 디렉터리 역할
- **프로젝트 루트 (`src/`)**: Spring Boot 백엔드 (비즈니스 로직, DB 접근, REST API 제공)
- **`frontend/`**: React 프론트엔드 (현장 관리자·작업자용 웹 UI)
- **`docs/`**: 프로젝트 설계, 요구사항 명세, 로드맵, DB 초기화 SQL

---

## 4. 예상 사용자
- **생산 관리자**: 품목·거래처 관리, 작업지시 생성, 생산 현황 및 재고 대시보드 모니터링
- **현장 작업자**: 배정된 작업지시 확인, 완료 수량·불량 수량(생산실적) 입력, 자재 입출고 기록
